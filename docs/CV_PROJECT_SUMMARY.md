# ZAAD — Offline-First Bilingual Progressive Web App

**GitHub:** https://github.com/Usuf-Gomaa/zaad

**Tech stack:** React 19, TypeScript, Vite, React Router, IndexedDB/Dexie, Workbox, CSS, Vitest, React Testing Library, Playwright, Caddy, Git and GitHub.

- Developed a mobile-first Arabic/English PWA for personal du'as, daily planning and trip-specific Umrah progress, with RTL/LTR layouts and offline access.
- Implemented reliable autosave, serialized IndexedDB writes, versioned JSON backup/restore and compatibility checks to preserve personal drafts and progress.
- Built an explicit PWA update lifecycle with pending-write protection, multi-window activation checks and non-destructive refresh.
- Designed a structured editorial workflow for 51 religious records with evidence references, publication gating, source fingerprints and per-record JSON/CSV feedback exports.
- Validated application behavior with 39 unit/component tests, 10 Playwright browser tests and 20 local Caddy authentication, routing and cache scenarios; prepared protected reviewer staging and public hosting configurations.

Repository visibility is private because the complete source includes unapproved religious drafts. The website has not been deployed. Hosting preparation and partial source checking are not scholarly approval. Do not describe this project as an officially approved guide, a live public service, or a backend/account-based application.
