# Product scope

زاد is a charitable, independent Arabic personal pilgrimage companion, with no official affiliation. Primary navigation: يومي / دعواتي / مناسك العمرة / المزيد. The MVP prioritizes personal notes, flexible planning and offline stage tracking. Personal task completion and ritual tracking remain visibly separate. No worship scores or spiritual merit claims.

No accounts, subscriptions, ads, cloud notes, tracking, prayer-time API or permissions for location/camera/microphone. Hajj, media library and impact counters are intentionally disabled. Brand/domain availability and potential confusion with Nusuk's زاد service require checks before public launch.

Acceptance and limitations are in TEST_PLAN.md and IMPLEMENTATION_REPORT.md. The educational disclaimer is visible on the rites screen. Review-gated religious material must never be silently replaced with guesses.
