# ZAAD | زاد — دليل المشروع

**الإصدار الحالي: 0.4.0**

تطبيق ويب تقدمي لتنظيم الأدعية الشخصية والمهام اليومية ومتابعة رحلة العمرة، مع دعم العربية والإنجليزية وRTL/LTR، وحفظ تلقائي محلي، ونسخ احتياطي واستعادة، وتحديثات آمنة تنتظر اكتمال عمليات الحفظ.

**التقنيات:** React 19، TypeScript، Vite 6، React Router 7، Dexie/IndexedDB، Workbox، vite-plugin-pwa، CSS، Lucide React، Vitest، React Testing Library، Playwright، Caddy، Git وGitHub.

يوفر المشروع مساحة مراجعة منفصلة للأدلة والمصادر والملاحظات وتصدير JSON/CSV. كل السجلات الدينية الـ51 غير معتمدة حتى الآن؛ ولا تظهر الإرشادات غير المعتمدة في النسخة العامة. إعدادات الاستضافة المحمية موجودة ولم تُنشر على الإنترنت.

التوثيق الاحترافي الأساسي، ويشمل المعمارية والتشغيل والاختبارات والخصوصية والقيود والنشر، موجود في **[README.md](README.md)**. يُستخدم كمرجع أساسي لتجنب اختلاف نسختين كاملتين من التوثيق.
